# 08 日常驾驶

- **定位**：把「单会话里每天都要做的事」补齐，让 keel 在关掉方法论之后，用起来也不比普通 Claude Code 卡。状态：已定稿。最近更新：2026-08-17。
- **实现入口**：[模块设计/日常驾驶](../模块设计/日常驾驶.md) · [引擎](../模块设计/引擎.md) · [服务端](../模块设计/服务端.md) · [Web界面](../模块设计/Web界面.md) · [方法论](../模块设计/方法论.md) · [强制层](../模块设计/强制层.md) · [闭环编排器](../模块设计/闭环编排器.md)
- **所属里程碑**：[M9](../roadmap.md#m9)

## 拍板（2026-08-17）

1. **图片进对话**：粘贴、点回形针、拖文件；引擎类型已经能传图，本里程碑把服务端和输入框接上。
2. **读项目说明书**：`AGENTS.md` / `CLAUDE.md` 进系统提示；用户级只读 `~/.keel/MEMORY.md`。不读 `~/.claude`、不读 `~/.codex`。
3. **`@` 钉文件**：输入框打 `@` 选文件（和名册里的对话），发送时由服务端读进这一轮，不靠模型自己去翻。
4. **轻量计划模式**：先只读、出方案、用户点头再改代码。和模块设计确认并存——小改走计划，新模块仍走冻结。
5. **上报前自检**：类型检查不过不派 reviewer；测试按项目脚本跑，失败或超时打回实现对话。
6. **权限规则 + 危险命令**：在现有三档之上加 `allow` / `ask` / `deny`。内置危险清单即使 yolo 也再问一次。

## 要解决什么

M8 补的是「会不会上网、看不看得到页面」。那些接上之后，每天真正硌手的是另一批：

- 截图报错只能口述；
- 仓库自己的规矩进不去上下文；
- 想让模型看某个文件，得手打路径；
- 修一个小 bug 也没有「先看方案再动手」；
- 类型都红着还去花一轮 reviewer；
- 全放行之后，误敲一条毁数据的命令没有第二道网。

这些不抬下限的方法论，只让「退化成普通编程 agent」时也不别扭。卖点还是流程焊在基础设施里；本里程碑补的是方向盘手感。

## 和现有设计怎么相处

| 已有 | 本里程碑加上的 | 谁让谁 |
|---|---|---|
| 模块设计确认 / 冻结（[03](03-开发闭环与检查点.md)） | 轻量计划模式 | 新模块仍必须确认设计。计划模式不能当冻结的替身 |
| 审批三档 ask / edits / yolo（M5） | `ask` / `deny` 规则 + 危险清单 | 规则细，档位粗。yolo 仍被危险清单和 `ask` 规则拦住 |
| 方法论 base + 强制层 | `AGENTS.md` / `MEMORY.md` | 说明书是参考。和规范、闸冲突时，规范和闸说了算 |
| 绑定闭环（上报 → reviewer） | 上报前自检 | 自检过了才派 reviewer，省一轮冤枉钱 |

柔性原则不变：用户可以永远不进计划模式、不写 `AGENTS.md`、不 `@` 文件。缺的只是能力，不是新的硬流程。

## 六件事

### 1. 图片进对话

- `POST /sessions/:id/prompt` 增加 `images?: { mimeType, data }[]`（data 为 base64）。`text` 仍必填（可很短，比如「看这张图」）。
- `EngineSession.prompt` 把图和字一起交给 pi。消息类型里已有 `ImagePart`，本里程碑不再扩类型。
- Web 输入框：启用回形针；支持剪贴板粘贴、拖入。上限 4 张；单张超过 500KB 在浏览器压成 JPEG 再传。只收 `image/png`、`image/jpeg`、`image/webp`、`image/gif`。
- 当前模型的 `input` 不含 `image` 时，发送前就拒，文案写清「这个模型不看图，换一个或去掉图片」。
- 不做：PDF、Jupyter、语音、把图存进仓库。

### 2. 项目说明书与用户记忆

创建 / 恢复会话时，按这个顺序拼进系统提示，标清楚来源：

1. `~/.keel/MEMORY.md`（用户自己的习惯、偏好。跨项目。）
2. 项目根 `AGENTS.md`
3. 项目根 `CLAUDE.md`（和 2 不是同一文件才读；两份都在就两份都读）
4. `.keel/AGENTS.md`（本项目想单独写给 keel 的补充）

规则：

- 单份上限 32KB，超了截断并在提示里写一句「已截断」。
- 启动只读这些文件，不递归子目录，不解析 `@import`。
- **不读** `~/.claude/`、`~/.codex/`、`~/.pi/`。用户要复用，把内容拷进 `~/.keel/MEMORY.md` 或项目文件。
- 组装时加固定句：这些说明书是参考；与项目规范、强制层冲突时以规范和闸为准。
- 共享边界（把 [02](02-对话-子agent与模型选择.md) 的「全局记忆」落成文件）：`MEMORY.md` 只写偏好和习惯；需求、代码事实、密钥、项目决策写在项目文件里，不写进用户级。

`keel init` 不强制生成 `AGENTS.md`。没有这些文件就当没有，不报错。

### 3. `@` 钉文件 / 对话

- 输入框打 `@` 弹出候选：当前项目的文件（`git ls-files`，没有 git 就浅扫一层，忽略 `node_modules` / `.git` / `dist`）+ 名册里未归档的对话。
- 发出去的是 `{ text, attachments?: { kind: "file" | "conversation", path?: string, sessionId?: string }[] }`。
- 服务端读文件：走现有安全路径（出不了项目根），二进制跳过，单文件 100KB、一次最多 10 个。读到的内容做成带路径的代码块，拼在用户字前面交给模型。
- 钉对话：只塞名册摘要（职责、最近在做什么、未决），不塞全文。
- 不做：模糊搜半个仓库、钉 git commit、钉 MCP 资源。

### 4. 轻量计划模式

会话两态：`act`（默认，现在这样）和 `plan`。

进 `plan`：

- 输入框一颗 chip，点一下切。新对话默认 `act`，不跨对话记住。
- 系统提示加一段：你在做计划，只读，不要改文件；计划用 `keel_plan_submit` 交出来。
- `tool_call` 钩子拒写入类工具（write / edit / 同类）和unsafe 的 bash（复用现有 `isSafeCommand`）。只读工具放行。
- 模型调用 `keel_plan_submit({ title, steps, risks, outOfScope })` 后，时间线出计划卡。

用户在卡上三选一：

- **批准并执行**：态回到 `act`，系统按这份计划发一条执行指令，开始改。
- **改**：留在 `plan`，用户打字补充，模型再交一版。
- **取消**：回到 `act`，不当成批准。

和设计确认的边界：

- 新模块、新设计系统、会改数据含义的方案 → 仍走「写模块设计 → 批注 → 回显 → 冻结」。计划卡里若任务是新模块，必须有一步「先写/改模块设计并走确认」，批准执行也不能跳过冻结闸。
- 修 bug、改一个接口、补测试、改文案 → 只走计划模式就够，不强迫写模块文档。

不做：自动对每个任务进计划、Shift+Tab 快捷键（等 TUI）、计划文件单独存一份到仓库（会话条目够回放）。

### 5. 上报前自检

`keel_batch_report` 在派 reviewer **之前**先跑：

| 项 | 怎么判定 | 不过就怎样 |
|---|---|---|
| 类型检查 | 有 `typecheck` 脚本跑它；否则有 `tsc` / `cargo check` 就跑 | 打回实现对话，不派 reviewer |
| 测试 | 有 `test` 脚本就跑；超时（默认 90 秒）也算不过 | 同上 |

`.keel/config.json`：

```json
{
  "precheck": {
    "typecheck": true,
    "test": true,
    "timeoutMs": 90000
  }
}
```

两项都默认开。关掉进仓库，跟其他逃生舱一样留痕。没有对应脚本就跳过那一项，不报失败。

自检输出尾巴写进打回原因，实现对话能看见。不启动 dev 服务器（页面核对是 [M8](../roadmap.md#m8) 浏览器挂钩的事）。

### 6. 权限规则与危险命令

现有 `permissions.mode` + `allow` 前缀保留。加上：

```json
{
  "permissions": {
    "mode": "edits",
    "allow": [],
    "ask": ["git push", "git reset"],
    "deny": []
  }
}
```

判定顺序（先到先得）：

1. **`deny`**：直接拒，不弹窗。yolo 也拒。
2. **内置危险清单** 和 **`ask`**：即使 yolo 也弹审批卡。
3. 再走现在的 mode + `allow` + 安全前缀。

内置危险清单（人话，实现时写成可测的匹配）：

- 删盘、格式化、关机；
- `rm -rf` 打到仓库根或系统目录；
- `git reset --hard`、`git clean -fd`、`git push --force`、往 `main` / `master` 推；
- `curl … | sh`、`wget … | bash` 这类把网上下来的东西直接喂给壳；
- 宽路径 `chmod 777`。

第一版匹配保持简单，和今天的 `allow` 一样走命令前缀 / 工具名 / `path:` 前缀（管写入路径）。不做 Claude Code 那种完整规则语法。

设置页「项目」把三份列表摊开；内置危险清单只读展示，避免用户不知道 yolo 其实还问。

## 明确不做

- 子目录分层 `CLAUDE.md`、`.claude/rules/`、`@import`（说明书先读根上的就够）
- PDF / 语音 / Jupyter
- 自动对每个任务进计划
- OS 级沙箱、按域名管 MCP
- 用户任意 hooks（[M10](../roadmap.md#m10)）
- 对话检查点、手动压缩、后台任务、worktree（[M10](../roadmap.md#m10)）
- VS Code 选中即发、diff 按块接受、TUI（[M6](../roadmap.md#m6) 及更后）

## 配置对照

`.keel/config.json` 本里程碑增加的字段（其余不动）：

```json
{
  "precheck": { "typecheck": true, "test": true, "timeoutMs": 90000 },
  "permissions": {
    "mode": "edits",
    "allow": [],
    "ask": [],
    "deny": []
  }
}
```

用户级：`~/.keel/MEMORY.md`（可选，人写的 markdown）。

会话：`SessionMeta.extra.mode = "act" | "plan"`。

## CLI / Web / 服务端

- **Web**：回形针可用；`@` 弹出；计划 chip + 计划卡；项目设置里的权限三列表 + 只读危险清单。
- **服务端**：`/prompt` 收图和 attachments；读说明书在创建会话时做；`POST /sessions/:id/plan/approve|revise|cancel`。
- **CLI**：`keel init` 写出 `precheck` / `permissions` 默认段；`keel doctor` 提一句「项目根有没有 AGENTS.md / CLAUDE.md」（有就报读到了，没有不当错误）。
- **无头 `keel run`**：计划模式不自动进；危险清单在无头里变成直接拒（没人点审批卡），避免 CI 里把盘删了。
