# 并行与安全网

- **模块定位**：多件事同时干、离开屏幕能喊人、改坏了能退、团队能把约定挂在事件上。不新增包，能力拆进现有包。
- **对应代码**：引擎会话 cwd / 压缩 / 截断；名册 `conversations/create.ts`（`worktree`）；子 agent `subagents/run.ts`（`background`）；服务端通知与 compact / rewind 路由；Web 用量环、任务面板、退回入口、通用通知开关；强制层 `hooks` 配置与挂载。
- **所属里程碑**：[M10 — 并行与安全网](../roadmap.md#m10)
- **当前状态**：未开始（设计已定，见 [设计/09](../设计/09-并行与安全网.md)）
- **最近更新**：2026-08-17
- **设计依据**：[设计/09](../设计/09-并行与安全网.md)

## 职责与边界

做：

- 给对话建 / 清 git worktree，会话 cwd 指过去。
- 每轮记检查点，按轮退对话，可选带上 M8 文件回滚。
- 上下文分项、手动压缩、丢掉历史新开一条。
- 后台子 agent（长 shell 只在 pi 已支持时打开）。
- 本机 / 浏览器通知。
- 项目钩子；用户级钩子按 `allowUser` + 理由加载。

不做：

- 图片、说明书、计划模式、危险清单（[日常驾驶](日常驾驶.md)）。
- OS 沙箱、远程接管、Agent Teams。
- 自造第二套 PTY。
- 文件快照本身（[扩展与技能](扩展与技能.md) 的 `rewind`）。

## 结构与数据流

```
keel_conversation_create({ worktree: true })
         │
         ▼
git worktree add .keel/worktrees/<id>
session.cwd = 副本
子 agent 继承 cwd

每轮用户消息
         │
         ▼
keel/checkpoint 条目（最多 20）
         │
         ▼
POST /sessions/:id/rewind { checkpointId, includeFiles }
  截断或 fork 会话
  includeFiles 且有 rewind 能力 → 调文件回滚

keel_agent_run({ background: true })
         │
         ▼
立刻回 job id
干完 → keel/subagent-done + WS + 通知

tool_call
  强制层 → 审批 → 项目 pre_tool_use →（可选）用户 pre_tool_use
  任一拒 → 停
```

`shouldNotify`、`pickWorktreePath`、`trimCheckpoints` 做成纯函数。

## 关键决策

1. **同模块仍默认串行**。worktree 是隔离，不是鼓励对着同一模块开打。
2. **不自动把副本合回主仓**。合是对话自己的活。
3. **对话回滚和文件回滚分开说**。
4. **不自造 shell 后台**。pi 没有就本里程碑不做长命令后台。
5. **钩子不能翻转强制层的拒绝**。和扩展同一条单调原则。
6. **用户级钩子默认关**，纪律抄 [设计/07](../设计/07-能力插槽与扩展.md)。

## 当前实现

无（相对本模块）。相关现状：

- 并行办法：每个 worktree 各起一份 `keel serve`。
- 压缩事件有，UI 只有用量环。
- 子 agent 同步等结果。
- 没有通知，没有用户钩子。
- M8 未开始：文件回滚要等默认集 `rewind`。M10 的「连文件一起退」在 M8 没就绪时只退对话。

## 验证方式

- worktree：临时 git 仓创建带 `worktree: true` 的对话，写文件只出现在副本，主树干净；归档且无未提交改动时副本被删。
- 检查点：三轮之后退到第一轮，第四轮的用户字从当前会话消失。
- 压缩：手动压一轮后用量下降，事件有 `compaction_end`。
- 后台：`background: true` 的子 agent，父对话在它结束前能再收一条 prompt。
- 钩子：项目 `pre_tool_use` 对 `bash` 返回非 0，调用被拒；强制层已拒的 `write` 不会跑到钩子。
- 用户钩子：`allowUser` 关着时 `~/.keel/hooks.json` 不执行。
- 目验：切走浏览器标签，等对话空闲，系统通知出现。
