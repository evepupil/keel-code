# 服务端

- **模块定位**：本地服务进程。一个进程托管**多个工作区**（每个工作区一个 KeelRuntime，共享一个 EngineHost），对 Web 工作台和 CLI 提供 HTTP + WebSocket API：工作区、对话、子 agent、事件流、文件（设计文档读写与批注）、看板、审批、设置与凭据。只监听 `127.0.0.1`。
- **对应代码**：`packages/server/`
- **所属里程碑**：[M1 — 引擎与最小工作台](../roadmap.md#m1)、[M7 — 能力档 + 多工作区](../roadmap.md#m7)（日常驾驶 API 在 [M9](../roadmap.md#m9)，并行 API 在 [M10](../roadmap.md#m10)）
- **当前状态**：进行中（M1–M7 当前范围已落地；M9 / M10 API 仍待扩展）
- **最近更新**：2026-08-18

## 职责与边界

做：REST（Hono）+ WebSocket（ws）；工作区注册表（`~/.keel/workspaces.json`）与按需懒启动 / 闲置释放的工作区运行时；对话注册表（内存 + 会话文件扫描）；事件广播（按工作区 + 会话订阅，一条连接复用）；文件 API（限项目目录内，供批注编辑器读写 `docs/`）；设置与凭据读写（`~/.keel/`，跨工作区共享）；`keel web` 单实例状态（`~/.keel/web.json`）；原生选目录对话框。

不做：业务规则（对话调度、闭环、门禁在各自包里，服务端只是装配与暴露）；界面。

## 结构与数据流

```
Web / CLI ── HTTP(JSON) ──▶ routes/*  ──▶ services（装配 engine / roster / loop / docs 包）
          ◀─ WebSocket ────  events/broadcast ◀── engine 事件流 + keel 事件

packages/server/src/
  serve.ts          startServer：EngineHost + ModelSelector + WorkspaceManager + Hono/WS + 静态托管 + web.json
  app.ts            全局路由 + /api/w/:wid/* 懒加载转发到工作区子应用 + /ws
  runtime.ts        createKeelRuntime：一个工作区的组合根（引擎 + Hub + 审批 + 名册 + 闭环 + 文档 + MCP）
  workspaces/       registry（workspaces.json）、manager（懒加载 / 闲置释放）、web-state（web.json 探活）、pick-folder（原生选目录）
  routes/           workspaces / providers / settings（全局）；sessions / roster / docs / board / approvals（工作区级）
  ws/               一条连接复用：按 workspaceId+sessionId 订阅，事件 / 名册变化 / 审批都带 workspaceId
  services/         对 engine / roster / loop / docs 的装配
  auth.ts           本地令牌（启动时生成，Web 通过 URL 参数取得）
```

## 关键决策

1. **进程内直接持有引擎**，不走 RPC 子进程：单进程简单、事件零拷贝、Windows 少一层进程管理。
2. **一个进程多工作区**：`keel web` 单实例后台常驻，工作区运行时按需懒启动、闲置 30 分钟且没有会话在跑就释放；凭据 / 模型目录 / 设置 / 探测缓存全进程共享（EngineHost + 一个 ModelSelector）。`keel serve` 是前台别名。
3. **本地令牌**：即使只监听回环地址，也发一个随机令牌防止同机其他页面误连。

## 当前实现

`packages/server/src/`：
- `serve.ts`：`startServer({ cwd?, homeDir?, port, staticDir?, engineHost?, idleMs?, headless?, writeWebState? })`——建 EngineHost（或复用）、ModelSelector、WorkspaceRegistry + WorkspaceManager、生成本地令牌、Hono + `@hono/node-server`（`upgradeWebSocket` + `ws`）、可选静态托管 Web 构建产物（SPA 回退）；给了 `cwd` 就注册为工作区并预加载，`url` 直达 `#/w/<wid>`；`writeWebState` 写 `~/.keel/web.json`（端口 / 令牌 / pid），close 时清掉。返回 `{ url, port, token, engineHost, manager, workspaceId?, runtime?, close }`。
- `app.ts`：`/api/*` 挂令牌中间件；全局路由 `GET /health`（含 pid / 已加载工作区）、providers / models、settings / models/tiers、workspaces；`ALL /api/w/:wid/*` → `manager.get(wid)`（未注册 404、启动失败 500）→ 该工作区的子应用（`buildWorkspaceApp`：`new Hono().basePath('/api/w/<wid>')`，挂 project / sessions / roster / docs / board / approvals / mcp，按 wid 缓存，卸载时丢弃）→ 直接 `sub.fetch(c.req.raw)`；`/ws` 升级 WebSocket（令牌错 → 4401）。
- `workspaces/registry.ts`：`WorkspaceRegistry`（`~/.keel/workspaces.json`，`{ id, path, name, addedAt, lastOpenedAt }`，id = `projectDirName(path)` 与会话目录同名；`add` 去重并更新 lastOpenedAt、目录不存在抛错；`remove` / `touch` / 按最近打开排序）、`isProjectDir`（有 .git 或 .keel）。
- `workspaces/manager.ts`：`WorkspaceManager`——`get(id)` 懒建 `createKeelRuntime({ cwd, host, selector, headless })`（并发合并、`onLoaded` 通知 WS）；`add / remove / unload`；`sweep()` 每分钟：超过 idleMs 没被 HTTP / WS 碰过且没有会话在流式输出就 `unload`（`onUnloaded`）；`list()` 带 `loaded / isProject / exists`。
- `workspaces/web-state.ts`：`readWebState / writeWebState / clearWebState(home, onlyPid?)`、`isProcessAlive(pid)`、`pingWeb(state)`（GET /api/health 1.5 秒超时）、`webUrl(state, hash?)`。
- `workspaces/pick-folder.ts`：`pickFolder()`——Windows PowerShell（-STA + WinForms FolderBrowserDialog）、macOS osascript、Linux zenity / kdialog；返回 picked / cancelled / unsupported。
- `routes/workspaces.ts`：`GET /workspaces`、`POST /workspaces {path,name?}`（201）、`POST /workspaces/pick`、`DELETE /workspaces/:id`。`routes/settings.ts`：`GET/PATCH /settings`、`GET /models/tiers`（从 roster 路由挪出，全局）。
- `auth.ts`：`x-keel-token` 请求头或 `?token=`。
- `routes/providers.ts`：`GET /providers`（默认只列用户加过的；`?scope=all` 看全部）、`GET /providers/builtins`、`GET /providers/:id/catalog`、`PUT /providers/:id`、`DELETE /providers/:id`、`POST /providers/fetch-models`、`GET /providers/probe`、`PUT/DELETE /providers/:id/key`、`GET /models?available=1`。
- `routes/sessions.ts`：`GET /sessions?ensureMain=1`、`POST /sessions`（kind/title/role/model/thinkingLevel/initialMessage）、`GET /sessions/:id`（meta + messages + state）、`POST /sessions/:id/prompt`（202，事件走 WS）、`POST /sessions/:id/abort`、`PATCH /sessions/:id`（title/model/thinkingLevel/archived/role/pinned）。
- `hub.ts`：`SessionHub`——懒加载会话、事件扇出、创建时用方法论包组装系统提示、`ensureMain()`。
- `ws/ws-hub.ts`：`WsHub(manager)`——工作区加载时挂上该运行时的 `hub.onEvent / onSessionsChanged / approvals.onRequest / onResolved`，卸载时摘掉；客户端 `{type:"subscribe", workspaceId, sessionId}`（触发懒加载 + 打开会话）；推送 `event / sessions_changed / approval / approval_resolved` 都带 `workspaceId`，注册表变化推 `workspaces_changed`。
- `services/roster.ts`：装配名册 / 对话工具 / 子 agent（Hub 充当 `ConversationGateway`；创建 `ModelSelector`（能力档选择器）注入 runner / 工具 / 闭环，并 `hub.setModelResolver` 让没指定模型的新对话按 `tier` 或类别默认档落实）；`routes/roster.ts`：`GET /roster`、`GET /roster/:id`。`POST /sessions` 收可选 `tier`（light / standard / flagship）。`hub.create` 支持直接给 `systemPrompt` / `tools`（子 agent 用）。
- `runtime.ts`：`createKeelRuntime({ cwd, homeDir?, engine?, host?, selector?, headless })` 一个工作区的组合根——引擎（给了 host 就在宿主上建，共享凭据 / 设置）+ Hub + 审批（先于门禁注册）+ 名册（可复用共享 ModelSelector）+ 闭环 / 强制层 / 文档修剪 + 文档工具 + MCP；`serve`（HTTP + WS，多工作区）与 `keel run`（无头，单项目）共用。
- `services/approvals.ts`：审批（`.keel/config.json` 的 `permissions.mode`：yolo / edits / ask；`allow` 额外前缀），`tool_call` 守卫挂起 → WS 广播 `approval` → `POST /approvals/:id`（allow / deny / allow-session）→ 放行或拒绝；15 分钟超时视为拒绝；无头模式全放。`isSafeCommand`（只读 git / 查看 / 版本 / 项目门禁前缀；链式、重定向、命令替换一律不安全）。`routes/approvals.ts`。

## 验证方式

`server.test.ts`（真 HTTP + WS，mock 模型）：无令牌 401；providers / models / probe（全局）；添加 / 列目录 / 删除自定义提供方；`ensureMain` 自动建主对话；创建对话（职责段进系统提示）→ WS 订阅（带 workspaceId）→ prompt 202 → 收到 `message_update` / `idle` → GET 校验消息；PATCH 改标题；未知会话 404；工作区：列表 / 加入 / 首次访问才加载 / 未知 404 / 参数校验 / 移除后 404；WS 令牌错 4401。`workspaces/registry.test.ts`（加入去重排序移除、坏文件、isProjectDir）、`workspaces/manager.test.ts`（懒加载 / 事件 / 闲置释放 / 重新加载 / 移除）。
- 真实会话补充（2026-08-18）：`server.test.ts` 调用 `keel_design_freeze`，验证工具事件落入会话、冻结条目回读，以及文档写入冻结标记。

## 待扩展项

- 跨工作区待处理事项汇总接口（前端重构时一起做）
- 远程访问 / 鉴权（不在 v1 范围）
- **扩展 API**（[M8](../roadmap.md#m8)）：`GET/PATCH /api/w/:wid/extensions`（列表、开关、健康）；安装任务第一版可不做（CLI 装）。运行时把 `allowExtra` 决议传给引擎加载器。
- **日常驾驶 API**（[M9](../roadmap.md#m9)）：`/prompt` 收 `images` 与 `attachments`；创建会话时读说明书；`POST /sessions/:id/plan/approve|revise|cancel`。
- **并行与安全网 API**（[M10](../roadmap.md#m10)）：创建会话可带 `worktree`；`GET /sessions/:id/context`、`POST /sessions/:id/compact`、`POST /sessions/:id/rewind`；通知由服务端在对应事件上触发。
