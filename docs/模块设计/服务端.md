# 服务端

- **模块定位**：本地服务进程。持有引擎实例，对 Web 工作台和 CLI 提供 HTTP + WebSocket API：项目、对话、子 agent、事件流、文件（设计文档读写与批注）、git、设置与凭据。只监听 `127.0.0.1`。
- **对应代码**：`packages/server/`
- **所属里程碑**：[M1 — 引擎与最小工作台](../roadmap.md#m1)
- **当前状态**：进行中（M1 API 与 WebSocket 已落地）
- **最近更新**：2026-08-17

## 职责与边界

做：REST（Hono）+ WebSocket（ws）；项目工作区（一个进程服务一个项目目录，M5 多项目）；对话注册表（内存 + 会话文件扫描）；事件广播（每条对话一个频道 + 全局频道）；文件 API（限项目目录内，供批注编辑器读写 `docs/`）；git 只读查询与提交触发；设置与凭据读写（`~/.keel/`）。

不做：业务规则（对话调度、闭环、门禁在各自包里，服务端只是装配与暴露）；界面。

## 结构与数据流

```
Web / CLI ── HTTP(JSON) ──▶ routes/*  ──▶ services（装配 engine / roster / loop / docs 包）
          ◀─ WebSocket ────  events/broadcast ◀── engine 事件流 + keel 事件

packages/server/src/
  app.ts            创建 Hono 应用、挂路由、启动 ws
  routes/           projects / conversations / agents / files / git / settings / providers
  ws/               连接管理、频道订阅、事件序列化
  services/         对 engine / roster / loop / docs 的装配（组合根）
  auth/             本地令牌（启动时生成，Web 通过 URL 参数取得）
```

## 关键决策

1. **进程内直接持有引擎**，不走 RPC 子进程：单进程简单、事件零拷贝、Windows 少一层进程管理。
2. **一个项目一个进程**（v1）：`keel serve` 在项目目录运行；多项目管理放 M5。
3. **本地令牌**：即使只监听回环地址，也发一个随机令牌防止同机其他页面误连。

## 当前实现

`packages/server/src/`：
- `serve.ts`：`startServer({ cwd, homeDir?, port, staticDir?, engine? })`——建引擎、生成本地令牌、Hono + `@hono/node-server`（`upgradeWebSocket` + `ws`）、可选静态托管 Web 构建产物（SPA 回退）。
- `app.ts`：`/api/*` 挂令牌中间件；`/ws` 升级 WebSocket（令牌错 → 4401）。
- `auth.ts`：`x-keel-token` 请求头或 `?token=`。
- `routes/providers.ts`：`GET /providers`、`GET /providers/probe?providers=`、`PUT/DELETE /providers/:id/key`、`GET /models?available=1`。
- `routes/sessions.ts`：`GET /sessions?ensureMain=1`、`POST /sessions`（kind/title/role/model/thinkingLevel/initialMessage）、`GET /sessions/:id`（meta + messages + state）、`POST /sessions/:id/prompt`（202，事件走 WS）、`POST /sessions/:id/abort`、`PATCH /sessions/:id`（title/model/thinkingLevel/archived/role）。
- `hub.ts`：`SessionHub`——懒加载会话、事件扇出、创建时用方法论包组装系统提示、`ensureMain()`。
- `ws/ws-hub.ts`：按会话订阅 / 退订、`event` / `sessions_changed` 推送。

## 验证方式

`server.test.ts`（真 HTTP + WS，mock 模型）：无令牌 401；providers / models / probe；`ensureMain` 自动建主对话；创建对话（职责段进系统提示）→ WS 订阅 → prompt 202 → 收到 `message_update` / `idle` → GET 校验消息；PATCH 改标题；未知会话 404；WS 令牌错 4401。
