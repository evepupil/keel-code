# 方法论

- **模块定位**：提示词层本体。base 方法论提示词（所有对话共享）、主对话调度段、创建对话时的职责注入模板、子 agent 任务模板（reviewer / 重建认知）、反 AI 味清单、review 分类标准、验收简述模板。规则的「为什么」写在这里，「绕不过去」交给强制层。
- **对应代码**：`packages/methodology/`
- **所属里程碑**：[M1 — base 提示词接入](../roadmap.md#m1) → [M2 — 主对话调度段与职责注入](../roadmap.md#m2)
- **当前状态**：未开始（M0 仅骨架）
- **最近更新**：2026-08-17

## 职责与边界

做：提示词片段的定义、组装函数（`buildSystemPrompt({ kind, role, roster, constraints })`）、模板变量插值。不做：运行时决策。

## 结构与数据流

```
packages/methodology/src/
  base/          方法论 base（分节：这是什么 / 你是哪条对话 / 核心工作流 / 绑定循环 / 两类检查点 / 对话协作 / 硬规则 / 前端硬规则 / review 规则 / 文档规则 / 柔性原则）
  main/          主对话调度段（创建 / 路由 / 选模型 / 交接 / 归档的准则）
  roles/         职责注入模板 + 子 agent 任务模板（reviewer、重建认知、文档修剪）
  assemble.ts    组装：base + kind 段 + 职责 + 名册导航 + 当前约束状态
```

## 关键决策

1. **一份 base，所有对话共享**；主对话只多一段调度职责；职责段创建时注入。
2. **提示词讲 why**，硬规则由强制层兜底；两处措辞同源（从同一份规则常量生成），避免漂移。
3. 选模型准则写进主对话段：任务性质 → 档位；reviewer 默认与实现者不同模型；用户锁定优先。
